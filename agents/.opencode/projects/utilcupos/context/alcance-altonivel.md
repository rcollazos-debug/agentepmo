# ALCANCE DE ALTO NIVEL

- Objetivo general: Implementar el modulo de Utilizacion de Cupos para Bancoomeva.
- Entregables principales: Validacion de cliente, consulta de cupos, parametrizacion de cupos y cuentas, gestion de desembolsos, confirmacion y ejecucion final, evidencias de pruebas e informes de seguimiento.
- Exclusiones principales: No se construye la mediacion `utilizarCupos`; debe ser provista por Interoperabilidad.
