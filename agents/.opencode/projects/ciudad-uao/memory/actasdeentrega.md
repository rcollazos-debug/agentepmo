---

## Instrucciones de uso

- Registrar cada entregable aceptado formalmente por el cliente con firma o confirmación escrita.
- Un entregable solo se considera "aceptado" cuando el cliente firma el acta o envía confirmación escrita (email, mensaje formal).
- Las actas son evidencia en caso de disputas contractuales.
- Si el cliente no acepta formalmente → escalar según protocolo de cierre.

## Reglas de Aceptación del Proyecto

1. El cliente tiene **[N días] hábiles** para revisar y aceptar cada entregable desde la fecha de entrega.
2. Si el cliente no responde en ese plazo → se considera **silencio positivo** (o se activa el protocolo del playbook `cliente-ausente`).
3. Ningún entregable se considera aceptado sin confirmación escrita del cliente.
4. Los rechazos deben documentarse con causa específica y plan de corrección.
5. Las correcciones posteriores al plazo de garantía pueden generar un CR adicional.
