# PLANTILLA: Status Report Ejecutivo

> Usar con el command `/status` o el skill `informes-ejecutivos`.
> Frecuencia: quincenal o mensual. Audiencia: sponsor + cliente + dirección.
> Máximo 1-2 páginas. Formato ejecutivo — directo, con datos, orientado a decisiones.
