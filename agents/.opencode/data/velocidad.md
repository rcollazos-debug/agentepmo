## Velocidad Promedio por Cálculo

**Últimos 3 sprints:**
```
Promedio = (Sprint N + Sprint N-1 + Sprint N-2) / 3
         = (X + X + X) / 3
         = X SP/sprint
```

**Nota:** Para el Sprint 0 o primeros 2 sprints, usar estimación conservadora basada en el equipo:
```
Estimación inicial = (Número de desarrolladores × días por sprint × horas efectivas/día) / factor de conversión
```
