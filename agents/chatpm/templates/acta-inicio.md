## 2. PROPÓSITO Y JUSTIFICACIÓN DEL PROYECTO

Desarrollar una plataforma web a medida con arquitectura de microservicios que permita al cliente optimizar sus procesos de negocio, mejorar la eficiencia operativa y proporcionar una experiencia moderna a sus usuarios finales.

---

## 3. DESCRIPCIÓN DEL PROYECTO

### Tipo de proyecto
Desarrollo de software a medida - Plataforma web con arquitectura de microservicios.

### Alcance de alto nivel

**Lo que INCLUYE el proyecto:**
- Desarrollo de backend con Java Spring Boot (microservicios)
- Desarrollo de frontend con Angular
- Base de datos y persistencia
- Despliegue en ambiente de producción
- Múltiples módulos funcionales según backlog acordado
- Documentación técnica y de usuario
- Capacitación básica al equipo del cliente

**Lo que NO INCLUYE el proyecto:**
- Integraciones con sistemas externos (salvo que se definan en requisitos)
- Capacitación extendida o certificación de usuarios
- Soporte post-implementación (salvo acuerdo separado)
- Personalización de terceros no contemplada en alcance
