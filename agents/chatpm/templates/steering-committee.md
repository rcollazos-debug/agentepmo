# PLANTILLA: Comité Directivo / Steering Committee

> Usar con el command `/comite` o el skill `informes-ejecutivos`.
> Audiencia: Steering Committee, sponsor ejecutivo, dirección del cliente.
> Estructura diseñada para 60-90 minutos de reunión.
> Formato: presentación ejecutiva + acta integrada.
