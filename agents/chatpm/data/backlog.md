## Definición de Listo (Definition of Ready — DoR)

Una historia está lista para entrar a un sprint cuando:
- [ ] Tiene descripción clara en formato "Como [rol], quiero [funcionalidad] para [beneficio]"
- [ ] Tiene criterios de aceptación definidos y verificables
- [ ] Fue estimada por el equipo
- [ ] Las dependencias están identificadas y resueltas o planificadas
- [ ] El PO la priorizó en el backlog

## Definición de Done (Definition of Done — DoD)

Una historia está done cuando:
- [ ] Código completo y funcional
- [ ] Code review completado
- [ ] Pruebas unitarias pasando
- [ ] QA funcional completado sin defectos críticos
- [ ] Desplegado en staging
- [ ] Criterios de aceptación validados por PO
