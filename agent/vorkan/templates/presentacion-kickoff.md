# ANEXO: RIESGO R-001 - DETALLE

## ⚠️ Retraso en Entrega de Requerimientos

### Descripción
El cliente puede retrasar la entrega de los requerimientos funcionales necesarios para iniciar el desarrollo.

### Probabilidad e Impacto
| Factor | Valor |
|---|---|
| Probabilidad | 75% |
| Impacto | 40% |
| **Score** | **0.30 (ALTO)** |

### Plan de Mitigación

```
1. Solicitar compromiso formal por escrito
2. Establecer fechas límite claras
3. Monitoreo semanal del avance
4. Definir consecuencias del incumplimiento
```

### Trigger (Disparador)
Si el cliente se retrasa más de 3 días en la entrega de algún requerimiento, Monge lo contactará inmediatamente.

### Plan de Contingencia
Si el riesgo se materializa:
1. Replanificar sprint 1
2. Iniciar desarrollo de componentes independientes
3. Escalonar entregas del MVP
4. Evaluar extensión de fecha si es necesario
